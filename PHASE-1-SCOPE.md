# Phase 1 scope

Included: Next.js App Router, TypeScript, MySQL/Prisma schema foundation, env validation, migration setup, Prisma singleton, reusable UI primitives, centralized responsive design tokens, and a responsive visual homepage preview.

Not included yet: live restaurant routing, menu CRUD, customer ordering, table booking workflows, owner authentication, payment integrations, and production tenant authorization. These are deliberately deferred to later phases.
