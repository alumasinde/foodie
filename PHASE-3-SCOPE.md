# Phase 3 — Public website and quick menu

Included:
- Tenant public page remains `/r/[slug]` and loads only published restaurant data.
- Database models and migration for menu categories and items.
- Mobile-first menu section with featured meals, category filters, search, image support, KSh formatting and availability/sold-out labels.
- WhatsApp item enquiry link that pre-fills the selected meal and price.
- Empty states for restaurants with no menu data and searches with no matches.

Not included:
- Admin CRUD for categories/items (reserved for the admin phase).
- Cart, order placement, M-Pesa payments, delivery workflows or customer accounts.
- Hardcoded demo restaurant or menu data.
